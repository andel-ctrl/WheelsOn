WHERE u1 <> u2 AND NOT (u1)-[:CONECTA_CON]-(u2)
RETURN u2, count(DISTINCT amigo) AS amigos_en_comun ORDER BY amigos_en_comun DESC LIMIT 12;

Vacantes Laborales Sugeridas según tus Competencias

Ponderación basada en las habilidades que dominas frente a los requerimientos de ofertas abiertas.

// Consulta Cypher de Afinidad Laboral:
MATCH (u:Usuario {uid: '{{ uid }}'})-[:TIENE_HABILIDAD]->(h:Habilidad)<-[:REQUIERE]-(o:Oferta {estado: 'abierta'})
WHERE NOT (u)-[:POSTULA_A]->(o)
RETURN o, count(h) AS match_habilidades ORDER BY match_habilidades DESC LIMIT 12;

Recomendación de Colaboradores para Proyectos

Identifica talentos con las tecnologías del proyecto que además cuentan con conexiones en el equipo.

// Consulta Cypher de Afinidad de Equipo:
MATCH (p:Proyecto {pid: '{{ pid }}'})
MATCH (u:Usuario)-[:TIENE_HABILIDAD]->(h:Habilidad)
WHERE NOT (u)-[:PARTICIPA_EN]->(p)
RETURN u, count(h) AS tech_match ORDER BY tech_match DESC LIMIT 12;
